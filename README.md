# Bandgap-Voltage-Reference
Currently working on documentation.
Designed and implemented a high precision voltage reference circuit by balancing PTAT and CTAT characteristics to achieve a stable
temperature coefficient. The project involved the dimensioning of components for a target bias current of 5 µA and the integration of
a start up circuit to ensure reliable operation upon power up. To enhance performance, I conducted a detailed comparative analysis
between standard topologies and current mirror cascoding, validating the impact on power supply rejection and output stability
through comprehensive DC and transient simulations
